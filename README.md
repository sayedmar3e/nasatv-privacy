# NasaTV – Privacy Policy

**Last Updated: November 18, 2026**

NasaTV respects users' privacy and is committed to protecting their information.

### 1. Personal Information
NasaTV does not require users to create an account or provide personal information within the application.

### 2. Device Activation
Activation is provided free of charge through direct communication with the application administrator.

The device MAC address is required solely for activation purposes. According to the application operator, this address is not retained after activation is completed.

### 3. Data Collection
NasaTV does not directly request personal information from users. Limited technical information may be processed to provide the application's functionality.

### 4. Third-Party Services
The application may connect to external streaming services. Such services may process technical information according to their own privacy policies.

### 5. Children's Privacy
NasaTV does not knowingly request personal information from children.

This policy may be updated when necessary. Updated versions will be published on this page.
